Across the cowtest measurement interval, the deltas are 20,514 handler invocations, 20,484 lazy allocations, and 25 actual copies. Across the lazytest interval, they are 670, 662, and 4. These intervals include shell and memstat-command activity, so do not attribute every event to the test alone.

No net free-page loss is observed across the two targeted workloads and complete test suite: all four snapshots show 32,500. This is not a peak resident-memory measurement or a general proof of no leaks on other paths. The final screenshot explicitly shows ALL TESTS PASSED, with expected disk/inode exhaustion messages followed by OK.

Counters are cumulative since boot. The page_faults field counts handler calls, including kernel-copy recovery and rejected attempts, rather than hardware traps alone. A COW write that restores permissions on an exclusively owned page is counted as a handler invocation but not an actual copy. Initial nonzero counters include activity before and during the initial command. Swap counters/slots are zero because swap has not yet been implemented.
